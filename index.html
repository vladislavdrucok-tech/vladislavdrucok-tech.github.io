Join the Google Play closed test

Deep Bounce is currently available to enrolled Android testers through Google Play. The testing program is free to join.

  1. Join the Deep Bounce testers Google Group.
  2. Using the same Google account, opt in to testing on Google Play.
  3. Install the game through Google Play, test it, and send feedback about gameplay, performance, or bugs.

If the installation link is unavailable, check that your Google account has joined the group and opted in.
